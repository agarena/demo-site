HOW IT WORKS

声呐机房

这一页没有加载任何音频 —— 你听到的一切，都是振荡器、噪声与包络在你按下按钮的瞬间现场搭建的。

01 / REALTIME SYNTH

实时声源

16 首曲目全部由振荡器与增益包络现场合成：正弦波下扫的 Kick、高通白噪声的 Hi-hat、低通呼吸的锯齿贝斯、双失谐三角波叠成的 Pad，按 BPM 序列器无限循环。

02 / SPECTRUM SONAR

频谱声呐

AnalyserNode 的 fftSize 设为 512，64 根光柱对应 64 个频段；示波器波形叠加其上。声音的样子，被实时画在舞台墙上，随鼠标产生视差。

03 / BEAT REACTION

节拍响应

对 0-8 号低频桶求平均能量，超过滑动均值 1.3 倍且过了 refractory 间隔才判定为一拍；拍面强度以指数衰减写入全局 --beat 变量 —— 唱片放大、外框辉光、粒子爆发、标题、列表、卡片、播放条，整个房间与低音同步呼吸。

降级预案 若浏览器不支持 Web Audio，舞台将自动切换为「灯光演示模式」：多层正弦叠加驱动假频谱灯墙，进度由计时器模拟，全部交互照常可用。
