## 一、这是什么

这是一套按「主题 × 风格」批量设计的手写网页作品集，分两类：

- **标准网页（40 站）**：传统交互方式（导航/表单/轮播/弹层），仅视觉风格与布局不同；
- **炫酷网页（51 站）**：强交互/动效/3D 特效（three.js WebGL 场景、Canvas 粒子、滚动运镜、音频可视化等）。

覆盖主题：公司门户、个人博客、收集表、产品介绍、音乐网站、天体博物馆、漫画网站、日历网站、塔罗占卜、周易占卜、汽车展厅。
其中「个人博客」含 10 个 WebGL 沉浸式作品集型扩充变体（带 `WebGL` 徽标）。

## 三、接入你的门户（三种方式，按需选择）

### 方式 A：整包部署，作为独立作品集页（最简单）

1. 把整个 `portfolio-pack-v1/` 上传到任意静态托管（Nginx / OSS+CDN / GitHub Pages / Vercel / 虚拟主机均可）；
2. 门户导航里加一个链接指向 `index.html`（总画廊）即可；
3. Nginx 示例：

```nginx
location /portfolio/ {
    alias /var/www/portfolio-pack-v1/;
    index index.html;
}
```

### 方式 B：iframe 嵌入门户页面（推荐，体验最好）

每个站点都是自包含单文件，可直接 iframe。示例：

```html
<iframe
  src="https://你的域名/portfolio/cool/02-personal-blog/dream-clusters/index.html"
  title="梦境浮游 · 个人博客"
  loading="lazy"
  allow="autoplay"
  style="width:100%;aspect-ratio:16/9;border:0;border-radius:12px"
  sandbox="allow-scripts allow-same-origin allow-popups"
></iframe>
```

要点：
- `loading="lazy"`：滚动到可视区域才加载，避免首屏拖慢；
- `sandbox` 建议保留 `allow-scripts allow-same-origin allow-popups`（站点用到 localStorage 与外链）；
- 部分炫酷站含可选音频（默认关闭，需用户点击），如需允许自动播放再加 `allow="autoplay"`；
- **性能建议**：同屏 iframe 建议不超过 2–3 个 WebGL 站点；用 `loading="lazy"` + 展示页卡片点击后再载入预览（`embed-demo.html` 就是这个模式，可直接抄）。

## 四、注意事项

1. **联网依赖**：炫酷站使用的 three.js / GSAP 走公共 CDN（cdnjs/jsdelivr/unpkg 多级兜底）；离线打开时自动降级为 CSS 版（功能完整，但无 3D）。部署到门户后建议保持可访问公网。
2. **音频策略**：含音频的站点（音乐可视化、街机音效等）遵守浏览器自动播放策略，默认静音/需点击启动，不会打扰门户访客。
3. **数据隔离**：部分站点使用 localStorage 存草稿/主题偏好，键名互不冲突；如门户对 iframe 严格隔离，可去掉 sandbox 中的 `allow-same-origin`（站点仍可用，仅本地记忆失效）。
4. **移动端**：全部站点适配三档断点（≥1200/768/375）；WebGL 站在移动端自动减量（粒子/几何/分辨率）。
5. **外链说明**：作品库中的「工具链接 / 视频教程链接」为 `example.com` 占位演示链接，接入真实作品时替换为你的真实地址即可（每站内集中在数据数组的 `link` / `video` 字段）。
6. **版权**：全部代码与视觉均为本工程原创生成，可自由用于个人作品集展示。

## 五、如何更新/增删站点

- 增删站点后，同步更新 `manifest.json`（结构见上）与 `index.html` 画廊卡片即可；
- 每个站点完全自包含，删除一个目录不影响其他站点；
- 开发版工程（含调研文档 research/、台账 REGISTRY.md、全部源文件）保留在你的本地工作目录，本包是面向发布的精简快照。
